# ADR-002 — Ledger immutable + `stock_levels` sebagai cache

| Item | Detail |
| ---- | ------ |
| Status | Disetujui (simulasi architect). Berlaku saat PR T0.02 di-merge oleh Salman. |
| Tanggal | 6 November 2026 |
| Terkait | Architecture §9; task T0.02 |

## Konteks
Saldo stok harus bisa direkonstruksi 100% dan tahan terhadap pengeditan tidak sengaja (D-01).

## Opsi
1. Ledger append-only + tabel saldo sebagai cache
2. Hanya tabel saldo yang di-update
3. Event sourcing penuh

## Keputusan
`stock_movements` append-only (trigger `BEFORE UPDATE OR DELETE` menolak), `stock_levels` adalah cache `(location_id, product_variant_id)` yang diperbarui dalam transaksi yang sama. Koreksi lewat movement reversal. `inventory:verify` harian membandingkan cache dengan agregat ledger.

## Konsekuensi
+ Audit trail lengkap; saldo per tanggal dihitung dari ledger.
+ Satu pintu perubahan stok: `PostStockMovement` (AR-04).
- Penulisan lebih mahal (dua tulis per posting) dan perlu locking terurut untuk mencegah deadlock.
