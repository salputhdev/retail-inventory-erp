# ADR-004 — UI Livewire + Bootstrap; aturan widget JS Bootstrap

| Item | Detail |
| ---- | ------ |
| Status | Disetujui (PRD v0.2). |
| Tanggal | 6 November 2026 |
| Terkait | Architecture §9; task T0.02 |

## Konteks
Satu developer, aplikasi admin berat form dan tabel; tidak butuh SPA terpisah.

## Opsi
1. Blade + Livewire + Alpine + Bootstrap (Vite/Sass)
2. SPA (React/Vue) + API
3. Tailwind

## Keputusan
Blade + Livewire (class-based di `app/Http/Livewire`) + Alpine (bawaan Livewire) + Bootstrap 5 via Vite/Sass. Widget JS Bootstrap (modal, dropdown, toast, tooltip) dikendalikan Alpine atau dibungkus `wire:ignore`; `data-bs-toggle` dilarang di elemen yang di-morph Livewire (Architecture §6). Tanpa Tailwind.

## Konsekuensi
+ Satu bahasa/stack, tanpa lapisan API tambahan untuk UI.
+ Terbukti: modal tetap berfungsi setelah re-render (T0.04).
- Interaksi sangat dinamis (mis. PWA scanning Fase 3) butuh pekerjaan tambahan.
