# ADR-009 — Versi stack dikunci saat M0

| Item | Detail |
| ---- | ------ |
| Status | Disetujui (simulasi architect). Berlaku saat PR T0.02 di-merge oleh Salman. |

## Konteks
Versi harus dikunci sejak awal agar CI, Docker, dan staging konsisten (ISS-009: stack dipasang di versi terbaru atas perintah Salman).

## Opsi
1. Versi terbaru stabil saat M0, lockfile dikunci
2. Versi LTS/lebih lama
3. Versi mengambang

## Keputusan
Memakai versi stabil terbaru per 6 November 2026. `composer.lock` dan `package-lock.json` dikunci; upgrade minor/patch lewat PR rutin, upgrade mayor lewat ADR baru.

| Komponen | Versi |
| --- | --- |
| PHP | 8.5.12 (`composer.json`: `^8.5`) |
| Laravel | 13.40.0 |
| Livewire | 4.4.8 (Alpine bawaan) |
| Bootstrap | 5.3.8 |
| Vite / Sass | 8.3.6 / 1.107.1 |
| Node.js | 26.12.1 (Docker: `node:26-slim`) |
| PostgreSQL | 18 (`postgres:18`) |
| Redis | 8 (`redis:8-alpine`) |
| Pest / Larastan / Pint | 5.3.5 / 3.14.0 / 1.32.1 |

## Konsekuensi
+ Konsisten di lokal, Docker, dan CI.
- Versi mayor yang sangat baru berisiko bug/ekosistem belum matang; mitigasi: CI penuh dan lockfile.
- Hosting produksi harus mendukung PHP 8.5 dan PostgreSQL 18.
