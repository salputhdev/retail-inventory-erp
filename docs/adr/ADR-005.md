# ADR-005 — Redis + Horizon untuk queue, cache, session

| Item | Detail |
| ---- | ------ |
| Status | Disetujui (simulasi architect). Berlaku saat PR T0.02 di-merge oleh Salman. |
| Tanggal | 6 November 2026 |
| Terkait | Architecture §9; task T0.02 |

## Konteks
Import POS dan laporan berat harus berjalan di background; session dan cache harus mendukung banyak proses.

## Opsi
1. Redis + Laravel Horizon
2. Queue di database
3. RabbitMQ/SQS

## Keputusan
Redis untuk queue, cache, session, dan rate limit; Horizon untuk worker dan metrik, queue terpisah (`pos-import`, `reports`, `default`). Data Redis boleh hilang tanpa merusak konsistensi stok (PostgreSQL sumber kebenaran). Horizon dipasang di M3 saat dibutuhkan, bukan di T0.04.

## Konsekuensi
+ Throughput baik, dashboard queue bawaan.
- Satu komponen infrastruktur tambahan; job harus idempoten (IN-05).
