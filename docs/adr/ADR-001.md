# ADR-001 — Modular monolith Laravel, bukan microservice

## Konteks
Fase 1 dikerjakan satu developer dengan domain yang saling terkait erat (ledger, POS, rekonsiliasi). Transaksi lintas modul harus atomik.

## Opsi
1. Modular monolith (satu aplikasi, modul di `app/Domain/*`)
2. Microservice per domain
3. Monolith tanpa batas modul

## Keputusan
Modular monolith Laravel. Modul berkomunikasi lewat Action/Query class dan domain event (Architecture §2.2, AR-03). Forecast service Python (Fase 5) satu-satunya pengecualian terencana.

## Konsekuensi
+ Deploy dan debugging sederhana; transaksi DB tunggal.
+ Batas modul tetap ditegakkan lewat aturan AR-01..AR-07 dan code review.
- Disiplin batas modul harus dijaga manual; bisa dipecah belakangan bila perlu.
