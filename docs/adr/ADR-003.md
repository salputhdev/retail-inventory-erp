# ADR-003 — Scope lokasi: pivot `location_user` + global scope + Policy

| Item | Detail |

| Status | Disetujui (simulasi architect). Berlaku saat PR T0.02 di-merge oleh Salman. |
| Tanggal | 6 November 2026 |
| Terkait | Architecture §9; task T0.02 |

## Konteks
Setiap data transaksional milik satu lokasi; user hanya boleh melihat lokasinya (R-01, S-06). Sistem dirancang multi-lokasi sejak awal.

## Opsi
1. Pivot `location_user` + global scope Eloquent + Policy
2. Fitur *teams* spatie/laravel-permission
3. Skema/database terpisah per lokasi

## Keputusan
Pivot `location_user`, trait `BelongsToLocation` dengan `LocationScope`, dan Policy per model. Data di luar lokasi user menghasilkan 404. Bypass hanya lewat `withoutLocationScope()` yang eksplisit dan diaudit saat code review (AR-07).

## Konsekuensi
+ Tidak terikat fitur teams; mudah diuji dua arah.
+ Query terfilter otomatis, mengurangi risiko lupa filter.
- Job queue dan command harus membawa konteks lokasi eksplisit (diuji di T1.02).
