# ADR-007 — Alat browser testing: Pest browser (Playwright)

| ---- | ------ |

## Konteks
Alur kritis (penerimaan, import POS, stock count, approval) dan interaksi widget perlu diuji di browser (K-01).

## Opsi
1. pestphp/pest-plugin-browser (Playwright)
2. Laravel Dusk (ChromeDriver)

## Keputusan
Pest browser plugin (v5.2) karena satu runner dengan test lain dan dukungan multi-browser Playwright. Dusk (v8.7) cadangan bila plugin bermasalah. Test browser dijalankan harian di staging, bukan di setiap PR (menjaga CI ≤ 10 menit). Paket baru dipasang saat test browser pertama ditulis (T1.06), bukan sekarang.

## Konsekuensi
+ Satu ekosistem Pest.
- Butuh Node/Playwright di runner; menambah waktu CI bila dijalankan per PR.
