# ADR-008 — Costing weighted average di Fase 1; FIFO di Fase 2

| Item | Detail |
| ---- | ------ |
| Status | Disetujui (simulasi architect). Berlaku saat PR T0.02 di-merge oleh Salman. |
| Tanggal | 6 November 2026 |
| Terkait | Architecture §9; task T0.02 |

## Konteks
Costing memengaruhi nilai persediaan dan laba. Fase 1 belum punya batch/pengadaan.

## Opsi
1. Weighted average sejak Fase 1, FIFO lewat `cost_layers` di Fase 2
2. FIFO sejak Fase 1
3. Standard cost

## Keputusan
Weighted average: `avg_cost` dihitung ulang pada setiap movement masuk dan disimpan di `stock_levels`. Struktur data disiapkan agar `cost_layers` (FIFO) bisa ditambahkan di Fase 2 tanpa mengubah ledger.

## Konsekuensi
+ Sederhana dan cukup untuk Fase 1.
- Perpindahan ke FIFO di Fase 2 butuh migrasi nilai; dicatat sebagai pekerjaan WP2.
