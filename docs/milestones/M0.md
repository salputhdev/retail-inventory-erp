- CI di `main` hijau: Pint, Larastan (level 6), Pest + PostgreSQL 18 + coverage, audit dependensi, build Vite.
- Staging lokal: image produksi (`--no-dev`), Nginx + PHP-FPM, TLS 1.2/1.3, HSTS, CSP dasar; migrasi dijalankan; modal Livewire/Alpine/Bootstrap berfungsi di `https://localhost:8443` tanpa pesan console.

## 4. Catatan resmi T0.03

Kriteria Architecture §10.3 T0.03:
1. *Developer hanya berstatus kolaborator; pemilik organisasi adalah klien.* **Tidak berlaku (N/A, deviasi D4).** Repo berada di organisasi GitHub `salputhdev` yang dimiliki Salman; tidak ada pihak klien. Struktur yang sama (repo di organisasi terpisah dari akun pribadi) dipertahankan agar proses serah terima M6 tetap bisa disimulasikan.
2. *Push langsung ke `main` ditolak; merge butuh CI hijau dan 1 review.* **Terpenuhi** (proteksi branch aktif). Catatan: admin boleh bypass (`enforce_admins: false`) karena kontributor tunggal tidak bisa menyetujui PR sendiri. Bypass dipakai saat merge dan dicatat di riwayat PR.
3. *Template PR berisi checklist DoD (§12).* **Terpenuhi** (`.github/pull_request_template.md`).

Keputusan: T0.03 dianggap terpenuhi dengan deviasi D4 atas instruksi Salman (6 November 2026).
